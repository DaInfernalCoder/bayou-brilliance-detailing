## Stack

Dependency-free HTML, CSS, and JavaScript. The project contains no public form, email route, analytics tag, or runtime package dependency.

## Local check

```bash
python3 scripts/preflight_site.py .
python3 -m http.server 4176
```

In a second terminal, run browser QA if Python Playwright is available:

```bash
python3 scripts/browser_qa.py
```

Photography and font licensing are documented in `SOURCES.md`. Stock photos illustrate detailing context and are not presented as Bayou Brilliance employees, customers, vehicles, or completed work.
